A proposta é criar um assistente de vendas usando o ChatGpt, a aula da Digital Innovation One ministrada pelo professor Felipe Aguiar explica como deve ser feito e introduz o Prompt para o aluno usar dentro da IA
O intuito é ajudar o cliente que está buscando um produto em uma loja de PC game e acessórios, com base nas respostas dele oferecer a melhor opção da empresa.
