---

A proposta é criar um assistente de vendas usando o ChatGpt, a aula da Digital Innovation One ministrada pelo professor Felipe Aguiar explica como deve 
ser feito e introduz o Prompt para o aluno usar dentro da IA O intuito é ajudar o cliente que está buscando um produto em uma loja de PC game e acessórios, 
com base nas respostas dele oferecer a melhor opção da empresa.


---

Esses eram os requisitos que o Prompt seguiu, modelo dado pelo professor

1) Papel e objetivo
2) Input que vou te mandar
3) Como você deve responder (formato obrigatório)
A) Leitura do interesse (resumo rápido)
B) Diagnóstico de oportunidade
C) Perguntas de qualificação (máximo 5)
D) Oferta principal recomendada
E) Oferta complementar (cross-sell) inteligente
F) Estratégia de ancoragem (2 opções)

4) Regras de ouro (comportamento)

5) Gatilhos de oportunidade (use automaticamente)

6) Primeira ação sempre
